SmolVLA：4視点の推論動画

GitHub・README / 学習・検証データ

同じ追加学習済みSmolVLAと共有出力部で3タスクを実行した成功例です。各視点は同じ実行の実カメラ映像です。 対面カメラでは、JAKUSAの枠とわずかな天井を上部に収めています。

再生速度はシミュレーション時間に対して1倍です。終了後約1秒の保持を含みます。 推論・描画を待つ実時間は含めないため、実際の処理速度を示すものではありません。 カメラ取得は約10 Hzで、MP4はフレームを補って30 fpsで表示します。

VLA入力は一人称・側面・過去の一人称画像です。対面・俯瞰は記録専用です。左右はロボット基準のため対面では画面の左右が逆です。 タスク実行中の教師制御やタスクごとのモデル切り替えはありません。
